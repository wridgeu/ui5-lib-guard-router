# Compatibility with sap.m.routing.Router: test evidence

The test that proves each row of [Compatibility with `sap.m.routing.Router`](../../packages/lib/README.md#compatibility-with-sapmroutingrouter).

Differential tests run the same steps on a native router and on a guard router and compare what each records: hashes, history entries, routing events, titles, displayed views and log lines. The tests in `NativeCompat`, `NativeCompatTraces`, `NestedRouterParity`, `GuardedNavigationParity`, `GuardedEntryParity`, `flp-native-parity` and the vendored OpenUI5 router tests compare with the native router; a test from another file pins a behavior that differs on purpose. Where a guard blocks or redirects, the guard router is compared with the native navigation that the decision stands for: none for a block, a navigation to the target for a redirect. How the comparison works: [Upstream Parity](../reference/upstream-parity.md).

File names in "Proven by" are those of test files below `packages/lib/test/qunit/`; an `.e2e.ts` file is below `packages/demo-app/test/`.
